## 馬克杯 UV 配置

- **外側杯面:** V ∈ [0, 0.5]
- **杯底:** V ∈ [0.5, 0.99]
- **手把排除:** U ∈ [0.40, 0.60]
- **可印刷:** U ∈ [0, 0.40] ∪ [0.60, 1.00], V ∈ [0.059, 0.447]
- **攤平物理比:** 3.5:1
